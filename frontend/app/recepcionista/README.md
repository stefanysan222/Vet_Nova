Paleta oficial aplicada según vista Cliente / Design System:
- Azul principal: #2563eb
- Azul claro: #eff6ff
- Fondo general: #f8fafc
- Tarjetas: #ffffff
- Texto principal: #1e293b

- Bordes: #e2e8f0
- Éxito: #10b981
- Advertencia: #f59e0b
- Peligro: #ef4444

Instrucciones:
1. Copia la carpeta `recepcionista` dentro de tu `app/`.
2. Si ya tienes `app/recepcionista`, reemplaza los archivos.
3. Instala lucide-react si no lo tienes:
   npm install lucide-react
4. Entra a:
   /recepcionista
   /recepcionista/citas
   /recepcionista/clientes
   /recepcionista/mascotas
   /recepcionista/veterinarios
   /recepcionista/servicios
   /recepcionista/notificaciones
   /recepcionista/reportes
   /recepcionista/inventario
   /recepcionista/configuracion

Nota:
La carpeta `usuarios` queda como redirección a `clientes`, porque el menú recomendado usa Clientes.
